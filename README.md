# בוטן — האתר

אתר סטטי של בוטן: קודי קופון לאליאקספרס בישראל שנבדקו, ומדריכים. נבנה מ-`data/*.csv` ע"י `build.py`
ומתפרסם ב-GitHub Pages (בכל push ופעם ביום, כך שקודים שפג תוקפם נעלמים לבד).

## עדכון תוכן
- **ריבועי המוצרים** מגיעים אוטומטית מהבוט: כל מוצר שבוטן מפרסם בערוץ @Boten_deals נשמר בבוט ומוגש ב-`/products.json`. האתר נבנה מחדש כל שעה ומושך אותו (משתנה `BOT_FEED_URL`). כשלמוצר יש קוד מוכר, האריח מקבל מדבקה שפותחת את הבוט על המוצר (הקוד עצמו לא מודפס).
- `data/seller_codes.csv` — קודי מוכר (רק שנבדקו: `checkout` או `portal`)
- `data/platform_codes.csv` — סטים של קודי ישראל (ILAFF…) עם חלון תוקף רשמי
- `data/circulating_codes.csv` — קודים שמסתובבים באתרי קופונים ומה המצב שלהם; כל שורה נעלמת לבד אחרי `show_until`
- `data/checks.csv` — יומן בדיקות בקופה (כולל מה שלא עבד)
- `data/events.csv` — אירועי המבצע (11.11, בלאק פריידי…): מהם נבנים התפריט, הכרטיס הראשון ב"לפני שקונים" ו"האירוע הבא" בדף הקודים. אירוע נעלם לבד אחרי שנגמר
- `data/category_intros.json` — פתיח קצר לכל עמוד קטגוריה, עם קישור למדריך

## אם הבוט לא עונה בזמן הבנייה
האתר מפרסם ב-`/feed/` את העותק שהשתמש בו, ובבנייה הבאה חוזר אליו כשהבוט לא זמין (עד 72 שעות; עותק ישן יותר לא מוצג).

## כרטיסי שיתוף
`share_cards.py` מצייר לכל עמוד תמונת שיתוף 1200x630 ל-`_site/og/` (צריך `pip install pillow python-bidi`; בלעדיהם — הלוגו).

## דומיין משלכם
ב-Settings → Secrets and variables → Actions → Variables: `SITE_URL=https://example.co.il` ו-`CNAME=example.co.il`,
ואז Settings → Pages → Custom domain.

## הרצה מקומית
`python build.py` ← התוצאה ב-`_site/`.
לראות איך האתר ייראה בתאריך אחר (למשל אחרי 11.11): `BUILD_NOW="2026-11-20 10:00" BOT_FEED_URL=off python build.py`
